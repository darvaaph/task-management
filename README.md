# TaskFlow

Aplikasi tugas dan proyek berbahasa Indonesia untuk kuliah, kerja, dan rumah: Hari Ini, Inbox, Jadwal, dan Proyek, di desktop dan HP.

Saat ini aplikasi berjalan sepenuhnya di browser (tanpa backend). Data tersimpan di `localStorage`. Gunakan **Coba Mode Demo** di halaman masuk untuk melihat data contoh.

## Menjalankan

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # cek tipe + build produksi ke dist/
```

Butuh Node.js 20 atau lebih baru.
